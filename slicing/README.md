# Slicing Through

Прототип экшена на один палец в портрете (на десктопе — мышь, арена по центру). Проверяем одно: интересно ли ядро
без прокачки. Апгрейдов и меты пока нет — только рекорд.

- **Рывок:** зажми палец в любом месте, потяни и отпусти — ниндзя рванёт в ту сторону. Длина рывка — от длины протяжки
  (до 380 единиц при ширине арены 360). Палец не обязан быть на герое. Рывок отскакивает от стен (до 2 раз),
  прицел показывает весь путь.
- **Пока палец на экране, время идёт в 5 раз медленнее** — можно спокойно целиться.
- **Заряды:** 3, один копится 1.1 с. Рывок окупается со второго убийства: первое заряд не возвращает, каждое следующее — +1.
  Рывок без убийств сбрасывает комбо.
- **Очки:** 10 × комбо (до ×30). Попадание по герою сбрасывает комбо.
- **Враги** выходят группами по 3–6 из одной точки у края. Пехотинец идёт на тебя; щитоносец медленно разворачивается,
  удар в щит обрывает рывок, отбрасывает ниндзя и сжигает комбо — бей сбоку или рикошетом от стены в спину;
  лучник держит дистанцию 200–280, отбегает и стреляет каждые ~2 с по красной линии. Срезанная стрела возвращает заряд.
- **Волны** бесконечные, с каждой больше групп; каждые 3 волны +1 жизнь (из 3).

Код — `src/slicing/main.ts` (Canvas 2D), звук — общий `src/sfx.ts`. Все числа — константы в начале файла.
