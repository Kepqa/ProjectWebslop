# Slicing Through

Прототип экшена на один палец в портрете (на десктопе — мышь, арена по центру). Проверяем одно: интересно ли ядро
без прокачки. Апгрейдов и меты пока нет — только рекорд.

- **Рывок:** зажми палец в любом месте, потяни и отпусти — ниндзя рванёт в ту сторону. Длина рывка — от длины протяжки
  (до 250 единиц при ширине арены 360). Палец не обязан быть на герое.
- **Пока палец на экране, время идёт в 5 раз медленнее** — можно спокойно целиться.
- **Заряды:** 3, один копится 1.1 с. Каждое убийство возвращает заряд. Рывок без убийств сбрасывает комбо.
- **Очки:** 10 × комбо (до ×30). Попадание по герою сбрасывает комбо.
- **Враги:** пехотинец идёт на тебя; щитоносец медленно разворачивается, в лоб рывок отскакивает и оглушает его
  (оглушённого можно рубить с любой стороны); лучник держит дистанцию и стреляет по красной линии,
  стрелы срезаются рывком.
- **Волны** бесконечные, с каждой больше врагов; каждые 3 волны +1 жизнь (из 3).

Код — `src/slicing/main.ts` (Canvas 2D), звук — общий `src/sfx.ts`. Все числа — константы в начале файла.
