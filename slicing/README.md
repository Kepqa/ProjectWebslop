# Slicing Through

Прототип экшена на один палец в портрете (на десктопе — мышь, арена по центру). Проверяем одно: интересно ли ядро
без прокачки. Апгрейдов и меты пока нет — только рекорд.

- **Рывок:** зажми палец в любом месте, потяни и отпусти — ниндзя рванёт в ту сторону. Длина рывка — от длины протяжки
  (до 380 единиц при ширине арены 360). Палец не обязан быть на герое. Рывок отскакивает от стен (до 2 раз),
  прицел показывает весь путь.
- **Быстрый взмах — рывок сразу.** Если держать палец дольше 0.12 с, время замедляется до ×0.35 — можно прицелиться.
- **Заряды:** 3, один копится 0.7 с. Рывок окупается со второго убийства: первое заряд не возвращает, каждое следующее — +1.
  Рывок без убийств сбрасывает комбо.
- **Очки:** 10 × комбо (до ×30). Попадание по герою сбрасывает комбо.
- **Враги** выходят группами по 4–7 из одной точки у края. Пехотинец идёт на тебя; подрывник (с волны 2, в центре
  группы) при смерти через 0.12 с взрывается (радиус 70) и убивает соседей — убитые взрывом всегда возвращают заряд,
  подрывник в радиусе взрывается цепочкой; лучник держит дистанцию 200–280, отбегает и стреляет каждые ~2 с по красной линии. Срезанная стрела возвращает заряд.
- **Волны** бесконечные, с каждой больше групп; каждые 3 волны +1 жизнь (из 3).

Код — `src/slicing/main.ts` (Canvas 2D). Все числа — константы в начале файла.

Звуки — наборы Kenney «RPG Audio» и «Impact Sounds» (CC0, kenney.nl), `src/slicing/sfx/`, проигрыватель — `src/slicing/audio.ts`.
