# Дуэль

Бой один на один, вид сбоку, против бота (3 уровня) или вдвоём за одной клавиатурой. Раунды по 60 с, до двух побед.

- **Удар** — до трёх подряд, третий отбрасывает. **Сильный удар** — долгий замах, тратит выносливость, сносит блок.
- **Блок** режет урон, но ест выносливость; кончилась — блок пробит, оглушение.
- **Парирование** — блок за мгновение (0.16 с) до удара: враг оглушён, тебе мана; снаряды отражаются.
- **Кувырок** — короткая неуязвимость, можно прокатиться сквозь врага.
- **Заклинания** тратят ману, у каждого своя перезарядка. Удар во время каста или замаха — «Прервал!», +25% урона.

| Боец | Заклинания |
|---|---|
| Рыцарь (122 HP, медленный, сильный) | Рывок щитом · Боевой клич (+35% урона, без оглушения) · Молитва (+24 HP) |
| Маг (100 HP, быстрее копит ману) | Огненный шар · Молния (бьёт по месту через 0.6 с, не блокируется) · Скачок назад |
| Тень (104 HP, быстрая) | Кунай · Теневой шаг сквозь врага · Ядовитый клинок |

Клавиатура (один игрок): A/D или ←/→ — ходьба, W/↑ — прыжок, J — удар, K — сильный, S/↓/L — блок,
Пробел/Shift — кувырок, U I O (или 1 2 3) — заклинания. Вдвоём: игрок 1 — WASD, F, G, левый Shift, 1 2 3;
игрок 2 — стрелки, `.`, `/`, правый Shift, K L ; (или цифровой блок). На телефоне — экранные кнопки.

Графика процедурная (Canvas 2D, без спрайтов), звук — общий `src/sfx.ts`.
