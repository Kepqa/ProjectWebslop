# Swipe Survivors

Кооперативный (в планах) top-down выживач про зомби: бегаешь, на тебя прут орды, режешь их свайпами,
обводишь толпу печатью и собираешь апгрейды свайпа и тринкеты.

Стек: **Phaser 3 + TypeScript + Vite**, мобильные сборки — через **Capacitor** (Android/iOS).

## Управление

| | Сенсор (iPad / телефон) | ПК |
|---|---|---|
| Движение | плавающий джойстик: левые 40% экрана (в портрете — нижняя левая четверть) | WASD / стрелки |
| Удар | быстрый свайп в остальной части экрана | быстрый drag мышью |
| Печать | обвести зомби замкнутой петлёй | то же мышью |

- Свайп тратит энергию (голубая полоса). Медленный свайп — серый и не режет.
- Убить 3+ зомби одним свайпом — комбо и бонусный опыт.
- Толстяки и боссы роняют сундуки с тринкетами. Ящики ломаются свайпом (3 удара).
- Каждые 45 с — орда кольцом, каждые 90 с — босс (Гнилой Колосс / Матка Роя по очереди).

## Уровни

Каждый уровень длится **10 минут**: продержался — уровень пройден, открывается следующий (прогресс в `localStorage`).
Орда — каждые 45 с, боссы — на 2:00/4:00/6:00, за 90 с до конца приходит **Страж уровня** (усиленный босс).

| # | Уровень | Карта и механики | Новые враги | Боссы |
|---|---|---|---|---|
| 1 | Окраина | стены, ящики, холмы в 2 яруса с пандусами | прыгуны (ближе к концу) | Гнилой Колосс, Матка Роя |
| 2 | Разлом | **пропасти**: отброшенный в провал зомби погибает | прыгуны, подрывники | Скакун-Титан, Колосс |
| 3 | Некрополь | лабиринт комнат, ядовитые лужи, могилы призывают мертвецов | щитоносцы, призраки | Некромант, Матка Роя |

## Враги

| | Поведение |
|---|---|
| Ходок / бегун | базовый / быстрый и хрупкий |
| Плевун | держит дистанцию и плюётся кислотой — плевок можно разрубить свайпом (+3 энергии) |
| Таран | красная линия-предупреждение → рывок; врезавшись в стену, оглушён |
| Толстяк | много HP, свайп «пилит» его несколько раз за взмах, роняет сундук |
| **Прыгун** | заряжает прыжок (красный круг в точке приземления), перепрыгивает стены и пропасти, запрыгивает на плато |
| Подрывник | подбегает и взрывается; убитый — тоже взрывается и ранит соседей (цепные реакции) |
| Щитоносец | первые 2 удара свайпом только ломают щит; печать и взрывы — сразу |
| Призрак | ходит сквозь стены и ярусы |

## Поиск пути

Поле путей — Дейкстра от игрока по окну 112×112 тайлов, 8 направлений без срезания углов, со штрафом за клетки
вплотную к стенам и обрывам. Зомби идут к самой дальней точке пути, видимой «толстым» лучом (срезают углы
плавно), застрявшие отходят вбок и пересчитывают путь, запертые в недостижимых карманах переносятся.

## Звук

Все звуки синтезируются на WebAudio (без файлов). Защита от перегруза толпой: у каждого звука минимальный интервал
и лимит голосов, громкость частых звуков падает с плотностью событий, всё идёт через компрессор. Кнопка 🔊 в HUD.

## Отладка

- `?debug` — сцена доступна как `window.scene`
- `?time=60` — длительность уровня 60 с вместо 10 минут

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173, доступен и в локальной сети (--host)
npm run build      # продакшн-сборка в dist/
```

Поиграть на iPad без деплоя: `npm run dev`, затем открыть на iPad `http://<IP-компьютера>:5173`
(устройства в одной Wi‑Fi сети). Для полноэкранного режима — «Поделиться → На экран „Домой“».

### GitHub Pages

Workflow `.github/workflows/pages.yml` собирает и публикует `dist/` при пуше.
Один раз включить: **Settings → Pages → Source: GitHub Actions**.

### Android / iOS (Capacitor)

```bash
npx cap add android     # один раз, нужен Android Studio + SDK
npx cap add ios         # один раз, только на macOS с Xcode
npm run cap:android     # сборка веба, sync, открыть в Android Studio
npm run cap:ios         # то же для Xcode
```

Для выкладки в App Store нужен Apple Developer Program ($99/год).

## Структура

- `src/GameScene.ts` — игровой цикл: ввод, свайпы, печати, ИИ зомби и боссов, спаун, тринкеты, эффекты.
- `src/world.ts` — генерация карты (по параметрам уровня), высоты/пандусы/пропасти, коллизии, поле путей, отрисовка.
- `src/stages.ts` — описание уровней, прогресс.
- `src/sfx.ts` — процедурный звук.
- `src/textures.ts` — процедурные текстуры (рисуются в 2x для retina).
- `src/upgrades.ts` — все апгрейды/тринкеты и пересчёт статов из уровней.
- `src/hud.ts` — DOM-интерфейс: полосы, выбор апгрейда, экран смерти.
- Графика рисуется примитивами в рантайме — ассетов пока нет.
