# Swipe Survivors

Кооперативный (в планах) top-down выживач про зомби: бегаешь, на тебя прут орды, режешь их свайпами,
обводишь толпу печатью и собираешь апгрейды свайпа и тринкеты.

Стек: **Phaser 3 + TypeScript + Vite**, мобильные сборки — через **Capacitor** (Android/iOS).

## Управление

| | Сенсор (iPad / телефон) | ПК |
|---|---|---|
| Движение | плавающий джойстик: левые 40% экрана (в портрете — нижняя левая четверть) | WASD / стрелки |
| Удар | быстрый свайп в остальной части экрана | быстрый drag мышью |

- Свайп тратит энергию (голубая полоса). Медленный свайп — серый и не режет.
- Убить 3+ зомби одним свайпом — комбо и бонусный опыт.
- Толстяки и боссы роняют сундуки с тринкетами. Ящики ломаются свайпом (3 удара).
- Каждые 45 с — орда кольцом, каждые 90 с — босс (Гнилой Колосс / Матка Роя по очереди).

## Режимы

- **Сюжет — «прорыв», 4 главы.** Цель всегда видна (маяк + стрелка у края экрана), этапы «дойти» и «удержать».
  1. Здание: ключ-карта → генератор → выход (Страж — Колосс).
  2. Город: перекрёсток → радиовышка → эвакуация (Матка Роя); спящие группы на улицах замечают за 12 клеток.
  3. Мародёрство: заходи в дома — аптека → магазин → офис с картой → удержать двор (Некромант).
  4. Деревня: фермы, пруды, зомби-собаки и кабаны; осмотреть трактор → грузовик → починить пикап (Скакун-Титан).
- **Выживание.** 3 арены × 10 волн по минуте. Конец волны — передышка, волна 5 — босс, волна 10 — Страж арены,
  волны 3/7 — орда-кольцо, 4/8 — отряд толстяков. Зомби появляются группами.
- **Кооп.** Любой режим вдвоём по сети.

## Управление

Джойстик в компактной зоне нижнего левого угла (равномерная скорость), на клавиатуре — WASD; весь остальной
экран — под свайпы. Здоровье и энергия показаны полосками прямо под героем. Взятые предметы — в слотах
слева сверху (6 под свайп/формы, 4 под тринкеты, уровень — точками), как в Vampire Survivors.

## Физика

Зомби ходят стаями одним темпом и держатся кучкой. Тела плотные: в героя не влезают. Отброшенный зомби
передаёт импульс соседям — толпа валится как кегли. Взрывные бочки: клинок пинает и поджигает их,
взрывы поджигают соседние бочки цепочкой, герой может их толкать. Бочка ранит и героя — держи дистанцию.

## Комбо и счёт

Общая серия убийств: каждое убийство продлевает её на ~2.2 с, удар по герою срезает вдвое. Серия даёт множитель
счёта (до ×4), опыт, урон клинка (до +40%), энергию и шанс аптечек. Рубежи 25/50/100/200 — волна по врагам,
лечение, «Безумие». Конец длинной серии — бонус очков и опыта. Предметы вокруг комбо: Азарт, Метроном, Финишер.
Счёт и серия показаны по центру сверху.

## Ачивки и открытие предметов

20 ачивок; 17 предметов открываются ачивками (остальные доступны сразу). Меню «Предметы» — справочник
со всеми предметами, синергиями и условиями открытия; «Ачивки» — список с наградами.

## Настройки

Звук, «Мрачный стиль» (приглушённые цвета и круг видимости вокруг героя), «Левша» (джойстик справа).

## Необычные предметы (0.11)

Механики, а не голые статы. Свайп: Крюк (стягивает задетых к концу следа), Казнь, Трещина (третий удар
раскалывает), Ритм (каждый третий свайп в такт), Кровавый пакт (режь за HP), Контрудар (бей в момент атаки),
Кегли. Формы: Рикошет (шар от стен), Капкан, Аркан (петля стягивает толпу). Тринкеты: Метка охотника, Жнец
(души-снаряды), Чума (эпидемия), Жадность (опыт взрывается), Хронос (серия ×20 останавливает время),
Отталкивающее поле, Якорь (стой — бей сильнее), Оберег, Тотем, Бочкарь. Новые синергии: Воронка, Приговор,
Страйк, Эпидемия, Сломанные часы, Сшибка.

## Мастерская (прокачка между забегами)

За каждый забег — кости 🦴 (убийства, боссы, волны/этапы, бонус за победу). В меню «Мастерская»:
крепкое тело, острый край, выносливость, учёность, притяжение, лёгкий шаг, удача (+рерол), последний шанс.

## Враги

| | Поведение |
|---|---|
| Ходок / бегун | базовый / быстрый и хрупкий |
| Плевун | держит дистанцию и плюётся кислотой — плевок можно разрубить свайпом (+3 энергии) |
| Таран | красная линия-предупреждение → рывок; врезавшись в стену, оглушён |
| Толстяк | много HP, свайп «пилит» его несколько раз за взмах, роняет сундук |
| **Прыгун** | заряжает прыжок (красный круг в точке приземления), перепрыгивает стены и пропасти, запрыгивает на плато |
| Подрывник | подбегает и взрывается; убитый — тоже взрывается и ранит соседей (цепные реакции) |
| Щитоносец | первые 2 удара свайпом только ломают щит; печать и взрывы — сразу |
| Призрак | ходит сквозь стены и ярусы |

## Поиск пути

Поле путей — Дейкстра от игрока по окну 112×112 тайлов, 8 направлений без срезания углов, со штрафом за клетки
вплотную к стенам и обрывам. Зомби идут к самой дальней точке пути, видимой «толстым» лучом (срезают углы
плавно), застрявшие отходят вбок и пересчитывают путь, запертые в недостижимых карманах переносятся.

## Предметы, слоты и синергии

- **Слоты:** клинок (свойства свайпа + формы свайпа) — 6, тринкеты — 4. Когда слоты заполнены,
  предлагается только прокачка уже взятого — выбор становится реальным.
- **Карточки:** 🎲 реролл (2 на старте, +1 за каждого убитого босса), ⏭ пропуск (+20 HP).
- **Формы свайпа:** 🔱 Копьё, 🌊 Волна (след расходится своей формой), 🦋 Двойник (зеркальный свайп),
  ✴️ Веер осколков, ⭐ Звёздные мины, 🌀 Вихрь (на резком развороте свайпа), 🎯 Заряд (держи палец 0.5 с).
- **Синергии** (оба предмета ≥ 2 уровня): Огненная волна, Громовое копьё, Парные бумеранги, Кассетные мины,
  Смерч, Ледяные осколки, Пробой, Жажда, Двойная печать, Чёрная дыра. Карточка подсказывает пару.
- **Аптечки** выпадают из ящиков и могил (+25 HP), «Счастливая монета» повышает шанс.

## Онлайн-кооп (каждый со своего устройства)

1. Игрок 1: «Создать комнату» → получает код из 5 символов.
2. Игрок 2: вводит код → «Войти».
3. Игрок 1 выбирает уровень — игра стартует у обоих.

Как устроено: прямое P2P-соединение WebRTC через [PeerJS](https://peerjs.com). Бесплатный облачный сервер PeerJS нужен
только чтобы устройства нашли друг друга; бэкенд не нужен, всё работает с GitHub Pages. Хост симулирует мир
(`GameScene`), гость (`ClientScene`) двигает своего героя локально, шлёт свайпы хосту и рисует снимки мира
~15 раз в секунду (бинарный формат, ~16 байт на зомби, интерполяция).

В коопе: зомби идут к ближайшему живому игроку, их больше и боссы толще; опыт общий, апгрейды — у каждого свои
(на уровне оба выбирают карточку, игра ждёт обоих). Павшего игрока поднимает напарник — 3 секунды рядом.
Если напарник отключился, хост продолжает соло.

Для локальной разработки можно поднять свой сервер `peer` и открыть игру с `?peer=127.0.0.1:9000`.

## Пауза

Кнопка ⏸ (или Esc/P). Соло — сразу пауза (и автоматически при сворачивании вкладки).
В коопе — запрос напарнику: «Принять / Отклонить» (10 с на ответ, без ответа — отказ, повторный запрос через 20 с).
Продолжить может любой игрок — у обоих идёт отсчёт 3-2-1.

## Звук

Все звуки синтезируются на WebAudio (без файлов). На iOS звук включается по первому касанию; аудиосессия
переводится в режим playback, поэтому звук идёт и в беззвучном режиме. Защита от перегруза толпой: у каждого звука минимальный интервал
и лимит голосов, громкость частых звуков падает с плотностью событий, всё идёт через компрессор. Кнопка 🔊 в HUD.

## Режим разработчика

В меню 5 раз быстро нажать на заголовок «Swipe Survivors» → ввести код `ZOMBIDEV` (повторно — выключить).
Открывает все уровни и кнопку 🛠 в игре: бессмертие, бесконечная энергия, FPS, уровни/сундуки/все апгрейды,
спавн боссов и врагов, орда, перемотка времени, мгновенная победа, статистика игроков.
Код хранится в клиенте — это защита «от случайного игрока», а не от взлома.

## Статистика игроков

`src/stats.ts`: анонимные счётчики в бесплатном сервисе Abacus (без регистрации) — уникальные устройства
(+1 один раз на устройство) и число забегов (соло/кооп). Никаких личных данных не отправляется;
localhost и режим разработчика не считаются. Смотреть — в панели 🛠 или в меню в режиме разработчика.

## Версии

Номер версии — в `package.json` (SemVer), история — в [CHANGELOG.md](CHANGELOG.md). При выпуске:
поднять версию в `package.json` и добавить запись в журнал. Сборка кладёт рядом с игрой `version.json`;
открытая страница сверяется с ним и предлагает обновиться, если сборка устарела.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173, доступен и в локальной сети (--host)
npm run build      # продакшн-сборка в dist/
```

Поиграть на iPad без деплоя: `npm run dev`, затем открыть на iPad `http://<IP-компьютера>:5173`
(устройства в одной Wi‑Fi сети). Для полноэкранного режима — «Поделиться → На экран „Домой“».

### GitHub Pages

Workflow `.github/workflows/pages.yml` собирает и публикует `dist/` при пуше.
Один раз включить: **Settings → Pages → Source: GitHub Actions**.

### Android / iOS (Capacitor)

```bash
npx cap add android     # один раз, нужен Android Studio + SDK
npx cap add ios         # один раз, только на macOS с Xcode
npm run cap:android     # сборка веба, sync, открыть в Android Studio
npm run cap:ios         # то же для Xcode
```

Для выкладки в App Store нужен Apple Developer Program ($99/год).

## Структура

- `src/GameScene.ts` — игровой цикл: ввод, свайпы, печати, ИИ зомби и боссов, спаун, тринкеты, эффекты.
- `src/world.ts` — генерация карты (по параметрам уровня), высоты/пандусы/пропасти, коллизии, поле путей, отрисовка.
- `src/stages.ts` — описание уровней, прогресс.
- `src/sfx.ts` — процедурный звук.
- `src/net.ts` — P2P-соединение и бинарные снимки; `src/ClientScene.ts` — сцена гостя;
  `src/effects.ts`, `src/chunks.ts` — общая отрисовка эффектов и карты для хоста и гостя.
- `src/textures.ts` — процедурные текстуры (рисуются в 2x для retina).
- `src/upgrades.ts` — все апгрейды/тринкеты и пересчёт статов из уровней.
- `src/hud.ts` — DOM-интерфейс: полосы, выбор апгрейда, экран смерти.
- Графика рисуется примитивами в рантайме — ассетов пока нет.
